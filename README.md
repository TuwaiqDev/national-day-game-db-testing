National Day Game — Database Testing

Purpose
-------

This repository contains the database testing environment,
test cases, test data, execution results, and documentation
for the National Day Game database.

Testing Areas
-------------

01 — Base Data & Relationships
02 — Game Sessions
03 — Gameplay & Events

Workflow
--------

1. Tester receives assigned SQL test file.
2. Tester executes the test in Supabase SQL Editor.
3. Tester records Expected vs Actual Result.
4. Tester records PASS/FAIL.
5. Tester documents issues.
6. Tester commits changes to their branch.
7. Tester opens a Pull Request.
8. Reviewer reviews the results.
9. Approved changes are merged into main.

Repository Structure
--------------------

schema/
test-data/
testers/
documentation/
reports/

Privacy
-------

Only synthetic test data may be committed.
No production data, credentials, API keys,
passwords, or personal information may be stored
in this repository.
